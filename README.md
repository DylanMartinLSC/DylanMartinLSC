## Computer vision

| Project | What it does |
| :--- | :--- |
| **[musc-gpu](https://github.com/DylanMartinLSC/musc-gpu)** | A GPU-accelerated version of MuSc for zero-shot industrial anomaly detection. Scores unlabeled images and highlights defects without task-specific training. |
| **[musc-gui](https://github.com/DylanMartinLSC/musc-gui)** | A graphical interface for industrial anomaly detection, with camera, video, and image-folder workflows, reference samples, and defect heatmaps. |
| **[OpenTally](https://github.com/DylanMartinLSC/opentally)** | Count similar objects in a photo by boxing one example, correct the results, and export the tally. Runs in the browser, with optional local AI engines for harder scenes. |
| **[Curio](https://github.com/DylanMartinLSC/curio)** | A local identifier for coins, stamps, and other collectibles. Matches photos against catalog packs and shows reference images and similarity scores to help you compare results. |

## Creative tools

| Project | What it does |
| :--- | :--- |
| **[SketchLive](https://github.com/DylanMartinLSC/sketchlive-krea-alternative)** | A local, open-source take on a real-time AI drawing canvas. Sketch and write a prompt while a diffusion model updates an image preview on your GPU. |
| **[SketchLive Android](https://github.com/DylanMartinLSC/sketchlive-android)** | Sketch-to-image generation directly on Android. Download the model once, then draw and generate offline without a desktop server. |
| **[Doodle2Part](https://github.com/DylanMartinLSC/doodle2part)** | Turn a sketch into a live AI preview, then convert that preview into a colored 3D mesh you can rotate and download as a GLB file. Runs locally on your GPU. |

## Everyday tools

| Project | What it does |
| :--- | :--- |
| **[DealerStudio](https://github.com/DylanMartinLSC/DealerStudio)** | A Windows desktop app that turns vehicle photos into consistent dealership listing sets, with local background removal, cutout corrections, studio backgrounds, branding, and batch export. |
| **[Table to Excel](https://github.com/DylanMartinLSC/TableToExcel)** | Convert printed tables in images and PDFs into editable Excel or CSV files. Uses local OCR and includes a review interface for correcting extracted cells before export. |
